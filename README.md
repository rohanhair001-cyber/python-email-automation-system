# python-email-automation-system
A Python-based email automation system that sends personalized emails to multiple recipients using CSV data and SMTP integration.


## ⚙️ How It Works

1. User adds recipient details in `recipients.csv`
2. Python reads recipient information using CSV module
3. The system creates personalized email content
4. SMTP connects with email server
5. Emails are automatically sent to recipients
6. The program displays successful and failed email counts
